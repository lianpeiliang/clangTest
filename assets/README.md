# StructHex application icon

Source: Microsoft Fluent UI System Icons, **Code Block (48, Color)**.

- Original SVG: https://github.com/microsoft/fluentui-system-icons/blob/main/assets/Code%20Block/SVG/ic_fluent_code_block_48_color.svg
- License: MIT, copyright (c) 2020 Microsoft Corporation. See `LICENSE-FluentUI.txt`.
- `structhex.svg`: original vector artwork.
- `structhex.png`: transparent 256 × 256 rendering embedded as the Qt application icon.
- `structhex.ico`: Windows icon with 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel images.

The PNG is rendered from the SVG. The ICO contains resampled copies of that rendering. The artwork and colors are unchanged. Distribute the license with the icon and the application.
